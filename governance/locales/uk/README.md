# Нормативні документи InterDeadIT: українська версія

Англійські локальні джерела визначають чинні Профіль, Законодавство й ліцензійні декларації. Українські тексти мають інформативний статус `candidate` до окремої змістовної перевірки. [Походження та хеші](SOURCE.json) визначають точні джерела.

- [Установчий профіль](PROFILE.md), P01–P18, з локальним технічним профілем і винятками.
- [Законодавство екосистеми](legislation/ECOSYSTEM.md).
- [Ліцензія локальних нормативних документів](LICENSE.md).
- [Інформативний текст MIT](LICENSE-MIT.md).

Універсальна Конституція читається безпосередньо із закріпленого підмодуля: [English](../../../.code-constitution/locales/en/CONSTITUTION_CODE.md), [Русский](../../../.code-constitution/locales/ru/CONSTITUTION_CODE.md), [Українська](../../../.code-constitution/locales/uk/CONSTITUTION_CODE.md), [Беларуская](../../../.code-constitution/locales/be/CONSTITUTION_CODE.md). [Маніфест української upstream-локалі](../../../.code-constitution/locales/uk/LOCALE.json) зберігає її власний статус перевірки. Нормативний пріоритет універсального російського джерела зберігається.

[Спільна політика ліцензування](../../../.licensing-policy/README.md) і її еталонні тексти є зовнішніми джерелами. Права визначають наявні проєктні та піддеревні декларації й повідомлення третіх сторін. Саме підключення підмодуля не змінює ліцензій.
